# Portfólio | Geovani Galdino

One-page pessoal desenvolvido para a atividade de Desenvolvimento Web. A página apresenta minha trajetória, habilidades, projetos e formas de contato.

## Tecnologias

- HTML5
- Tailwind CSS via Play CDN
- GitHub Pages

## O que foi praticado

- Layouts com Grid e Flexbox.
- Responsividade com os breakpoints do Tailwind.
- Componentes reutilizáveis com `@apply`, como cards, tags e links sociais.
- Página estática, sem JavaScript próprio e sem formulário.
- Links externos somente para GitHub, LinkedIn e e-mail.

## Como executar

Abra o arquivo `index.html` no navegador ou rode um servidor local na pasta do projeto:

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

## Publicar no GitHub Pages

1. Envie estes arquivos para um repositório no GitHub.
2. No repositório, abra **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch principal e a pasta `/ (root)`.
5. Clique em **Save** e aguarde a publicação.

Como o arquivo `index.html` está na raiz, o GitHub Pages consegue iniciar o site diretamente. O endereço ficará parecido com:

`https://seu-usuario.github.io/nome-do-repositorio/`
